# C GLITCH GUY BOT

Bot WhatsApp public avec préfixe obligatoire `🍓`.

Exemples:
- `🍓menu`
- `🍓ping`
- `🍓alive`
- `🍓say Bonjour`

## Render
Build: `npm install`
Start: `npm start`

Variables:
- `PAIRING_NUMBER` = numéro WhatsApp au format international, chiffres seulement
- `CHANNEL_LINK` = lien de ta chaîne

Le panneau public est servi directement par Render à la racine `/`.
Ne mets jamais une clé/API secrète dans le HTML.
